What I actually do

Send me access, tell me what's wrong or what you want — I handle the rest.

$fix-bugs
Scripts erroring, features not working, server crashing. I dig through the resource, find the actual cause, and patch it — not a band-aid that breaks again next restart.
$build-scripts
Custom jobs, custom UI, custom anything. If it doesn't exist yet, I'll write it from scratch to fit how your server actually plays.

ESX, QBCore, QBox — full install or migration. Clean setup, configured for your server, no leftover junk from a template.

Server lagging or resmon numbers ugly? I'll profile it, find what's eating performance, and bring it down.
