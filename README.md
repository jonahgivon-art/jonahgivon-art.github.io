# 0xFix GitHub Pages Website

A static, no-build landing page for 0xFix. It is ready for GitHub Pages and uses only HTML, CSS, and JavaScript.

## Deploy

1. Upload the **contents** of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**, choose `main`, and choose `/(root)`.
4. Save. GitHub will publish the site at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Customize before publishing

- Replace each `https://discord.com/` in `index.html` with your own Discord invite URL.
- Update the service descriptions, testimonial text, stats, and prices to factual values.
- Add project screenshots under `assets/projects/` and point portfolio imagery to them if desired.
- The Google Font link is optional; the site still works if it cannot load.

## Files

- `index.html` — page content and SEO metadata
- `styles.css` — responsive design and animations
- `script.js` — terminal, counters, scroll animation, card tilt, and particles
- `assets/` — reserved for your logos, project images, and screenshots
